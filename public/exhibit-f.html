EXHIBIT F · CASE FILESOLSTICE DYNAMICS · SECURITY

Finally, a real break. A police contact recovers a laptop that matches your profile of the attacker — same time window, same digital fingerprints. It looks clean at first, like someone tried hard to erase what they'd done. The laptop is registered under a real name for the first time in this whole case: Arshb. Ghost_Fen finally has a face and a name behind the screen.

But deleting a file doesn't erase all trace of it. Hidden in the laptop's thumbnail cache is a photo with no matching file left on the disk — the original café photo that started this whole case. Someone deleted the evidence and forgot the cache still remembers it.

In the laptop's Prefetch folder, there's a second, quieter kind of proof: a record of every program this laptop ever ran, how many times, and exactly when each one last ran. Somewhere on that list is the tool Ghost_Fen used to break into the HR portal — and its timestamp lines up, almost to the minute, with the login Thahani's system flagged eleven days after that first photo was taken. A second timestamp, later on the list, sits much closer to the night Inchaf died than Thahani hoped it would.

THAHANI · DIRECTOR OF SECURITY "That's it," Thahani says quietly, looking at the timeline you've built — a café, a scouting photo, four security bugs, a signature in a log file, and now a tool and a timestamp that put him online within an hour of Inchaf's death. "That's everything I need to hand this to a detective, not just write up as a security report."
